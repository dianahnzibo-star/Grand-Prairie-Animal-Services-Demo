Grand Prairie Animal Services — Static Portfolio Demo

This version is fully static and requires no PHP or MySQL.

Portfolio updates:
- Uses Dianah's original Grand Prairie Animal Services logo hosted on WordPress.
- Uses the original Pexels hero photo supplied for the project.
- Uses linked Pexels pet photography for the sample pets.
- Pet inquiry and contact/volunteer forms are simulated in-browser and do not transmit data.

Open index.html locally or upload the folder to any static web host.
